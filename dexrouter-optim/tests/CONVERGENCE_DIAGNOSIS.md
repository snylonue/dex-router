# 收敛问题诊断

## 当前真实池修复与验收

以下新结果使用本地 539 池快照；后面的原始诊断保留修复前实验，不代表当前运行状态。
应用默认绝对残差价值容差保持 `1e-6`，库默认保持 `1e-8`，相对容差均为 `1e-8`。
验收对每个 token 检查 `|KKT gradient| * price <= absolute + relative * turnover * price`，
数学边界允许的导数方向不计入残差；数值价格保护下界不能代替数学下界。

| 配置 | 池 / token | 绝对容差 | 原始停止状态 / 路由验收 | 迭代 / 评估 | 最大 KKT 比率 | 最大负残差价值 |
| --- | ---: | ---: | --- | ---: | ---: | ---: | ---: |
| 默认筛选，库严格容差 | 159 / 95 | 1e-8 | MaxIterations / Approximate | 1798 / 10733 | 0.6694 | 0 |
| 关闭 TVL 筛选，应用现有容差 | 387 / 182 | 1e-6 | LineSearchFailed / Approximate | 4003 / 19469 | 0.7146 | 7.146e-7 |

`MaxIterations` 可能是单个重启块的停止原因，上表未用尽全局 5000 次迭代预算。
`Approximate` 仅在最终完整 KKT/负资金流检查通过时可用，并保留原始优化器停止状态。
完整集合修复前在同一应用容差下有约 21.7 美元的负残差，被拒绝；当前通过验收。
这些是离线浮点 CFMM 模型结果，不是链上逐笔整数执行或收益证明。

改动与根因：

- V3 不再直接相减两个舍入后的平方根。采用有理化差值，并用 FMA 保留
  `v0 * fee - v1 * current_sqrt^2` 的乘法误差，同时按准确差值选择方向和 tick 区间。
  流动性很大时，平方根小于一个 ulp 的价格差仍可能产生可观资金流。
- 部分成交与耗尽区间联合计算交易和非负支持函数值；在边界处从同一个精确价格差
  构造耗尽余量，避免价值/梯度不一致，也避免很小正目标被误判为耗尽至零价格。
- 重启使用当前价格附近的曲率探测，以及以当前价格为原点的仿射变量，避免
  `price / scale` 再乘 `scale` 引入一个 ulp 的起点扰动。
- 未通过残差验收的线搜索或重启块使用有界凸坐标恢复，仅评估关联池；与优化器共用
  全局预算，预留完整复验。只有验证支持函数变化有限且不为正时才保留恢复结果。
- 应用净资金流直接使用补偿求和的联合梯度，避免普通矩阵求和在很大的正反流中
  丢失小净值。真实回归另行重建全部交易并独立检查边界与资金流。

完整集合在库 `1e-8` 绝对容差下仍会如实返回 `NumericalStagnation`。
局部价格精度诊断固定其他价格时，wstETH 的相邻三个 `f64` 价格对应残差价值
约 `-2.649e-6`、`2.871e-7`、`3.223e-6`；weETH 对应约
`-1.510e-7`、`-4.270e-8`、`6.555e-8`。因此当前坐标附近的单变量价格格点
不能满足该严格容差。这不是全局不可解的证明：联合价格调整或更高精度仍可能改善。
不能仅提高迭代预算、忽略这类 token 或改报成功。

## 原始诊断结论

目前证据指向 **数值条件、浮点精度和停止准则为主要原因**，而不是已经发现了
自研优化器的确定性数学错误。也没有证据表明凸对偶目标整体或池梯度公式错误。
但求解边界存在独立的建模问题：统一正价格下界并非纯粹的数值缩放，会改变可行域。
自研优化器在病态问题上的效率和近精度极限时的终止处理仍值得改善。

这些结论不是“优化器已证明正确”或“所有真实池都已正确建模”的保证。

## 实验控制

[诊断驱动](<dexrouter-optim/tests/support/convergence.rs>)对两个优化器使用相同市场、
目标函数、解析梯度、价格初值、边界、memory=17、factr=0 和原始尺度 pgtol=1e-5。
默认对照都限定 1000 次迭代；扩展预算是 5000。评估上限为 50000，所列实验均未触及
生产默认的 10000 次评估上限。目标除以常数时，pgtol 也除以相同常数，避免靠放宽
梯度容差制造“收敛”。maxls=100 是仅自研的独立实验；参考实现保持其原始线搜索。

旧包装器 minimize 返回 Ok 不等于收敛，它丢弃底层 task。本实验使用公开 setulb
反向通信接口读取真实终止码，并仅对旧实现加锁。驱动另外用已知解的有界二次函数
验证。旧实现只增加为 dev-dependency；生产仍只调用自研求解器。

## 1. 合成 4096 池：精度和容差，而非特有实现错误

128 代币，V2/V3 混合，资本倍数 1：

| 求解器 | 状态 | 迭代 | 目标值 | 原始尺度投影梯度 |
| --- | --- | ---: | ---: | ---: |
| 自研 | LineSearchFailed | 31 | 12581.78586707 | 1.283e-5 |
| 参考 | LineSearchFailed | 28 | 12581.78586707 | 2.533e-5 |

目标值相对差仅 1.446e-16，价格最大相对差 1.028e-9。初值的有限差分梯度检验在
步长 1e-5 时，最差相对误差约 2.8e-7。自研 maxls 从 20 增至 100 仍失败：不是简单的
线搜索试探次数不够。

资本放大 1e6 后，两者目标值仍只差约 1.4e-15，相对价格差 6.6e-9；但原始梯度残差
约 27–38，远高于绝对容差 1e-5。原始 objective 已达 1.26e10，接近最优点时可实现的
微小下降容易低于 f64 的函数值分辨率。改变整体尺度或求和次序会改变终止状态，却
基本不改变最终解，这是近精度极限的重要证据。

factr=1e7 时两者都可返回函数下降收敛，但梯度残差更大。因此不建议只放宽 factr
来隐藏失败；需要与相对资金流/KKT 残差一起判断。

## 2. 真实 160 池：病态和预算，而非旧优化器能自动解决

96 代币，初始价格范围 1e-8 到 7.56e4，初始目标值约 3.06e6。同一进程、同一初值：

| 配置 | 自研 | 参考 |
| --- | --- | --- |
| 原始目标，1000 次 | MaxIterations，cost=2136.456，PG=6.353e4 | MaxIterations，cost=2019.097，PG=9.286e3 |
| 目标整体归一化，1000 次 | MaxIterations，cost=2215.447，PG=1.296e4 | MaxIterations，cost=2153.975，PG=6.521e3 |
| 原始目标，5000 次上限 | MaxIterations，cost=1191.240，PG=0.270 | 2745 次 LineSearchFailed，cost=1247.214，PG=600.6 |

PG 使用同一初始价格坐标计算。增加预算明显改善自研结果，且自研最终目标值更低；
不能据此把真实案例失败归因于自研实现独有错误。仅归一化目标并不能消除各坐标
曲率差异。

独立诊断运行在初始价格处估计的正 Hessian 对角元素，从 PEPE 的约 9.4 到 EUROC 的
1.96e9，跨度约 2.09e8。这是曲率不均匀的证据，**不是完整 Hessian 的精确条件数**。
手续费无交易区间和 tick 区间还会使局部曲率改变/变平，削弱有限历史拟牛顿模型。

独立预算实验运行在 4487 次后返回 LineSearchFailed，cost=1191.237645，残余负资金流
价值约 2.46e-4；以该点为共同初值重新缩放，两者都在零次成功迭代、21 次函数评估后
线搜索失败。这支持近最优阶段存在共同的数值分辨率/线搜索容差问题。

真实初值的逐池梯度检验（对每个分量扫描多个差分步长），最差相对误差约 7.4e-10。
近最优处差分会跨越手续费边界或受消减误差影响，不能将单一有限差分步长产生的大
误差直接认定为梯度公式错误。此检验不证明所有状态的市场实现都正确。

## 3. 价格下界确实是建模因素

[NonnegativeLinear 边界](<dexrouter-optim/src/utility/mod.rs#L64-L70>)返回 c + 1e-8，而
理论共轭的域是价格 >= c。非输出资产 c=0 时，统一 1e-8 下界对非常便宜的资产不是
可忽略的相对扰动。

保持其余配置和热启动一致，仅把非输出价格下界改为 1e-12/1e-16，1000 次后目标值
可从约 1191 降至 1136/1139，但这些新问题仍未收敛。这证明下界会影响可行域和目标，
**不证明那些数字是新问题的最优值**。它不是只把数字变小而保持原问题不变。

同样，在当前正下界下直接固定 USDC 到 1 也不保证等价：整体按锚点价格缩小后，
部分非输出价格可能违反其正下界。实验中固定锚点的 cost 约 4720，比自由锚点最终值
更高。不能为了改善条件数而不检查约束等价性就固定锚点。

## 后续顺序

1. 明确极小价格下界的业务语义，使其与资产单位和目标共轭相容，再判断能否等价地
   固定输出价格；不要把人为约束问题当成优化器参数问题。
2. 改善目标的稳定求值、坐标预条件和量纲归一化，并增加资金流/价值尺度相关的停止
   指标，不能只依赖绝对 pgtol 或函数下降状态。
3. 改善自研线搜索在浮点精度极限的诊断/终止处理，避免把数值停滞与真正坏方向混同；
   保留当前不接受未验证上升步的原则。
4. 保留新旧实现对照和较大预算测试。参考在部分配置下更快/残差更小，另一些配置下
   自研目标更低；这是实现效率与稳健性改进方向，而非已经定位的算法错误。

HashMap 邻接遍历会影响真实初值的路径选择，所以跨独立运行可能产生不同迭代轨迹。
上表每组新旧对照都在同一运行中共享初值；独立探针数据已单独标记。
